# MI Structure Viewer (порт 26.1.2)

Собственная реализация идеи мода MI Structure Viewer (автор KuDikan, исходники недоступны,
оригинал под JEI и All-Rights-Reserved — код и ресурсы оригинала НЕ использовались).
Политика флота: EMI-only (JEI/REI не подключаются).

Показывает все зарегистрированные мультиблочные формы Modern Industrialization
в виде отдельной EMI-категории с послойным просмотром.

## Что внутри

- EMI-категория `mi_structure_viewer:multiblock` и по одному EMI-рецепту на каждую
  зарегистрированную форму (включая варианты EBF по типам катушек).
- Карточка рецепта: имя машины, габариты (X×Y×Z), каркас (casing), вариант
  (для EBF — катушка), послойная сетка 18px, кнопки «предыдущий/следующий слой».
- Сводный список требуемых блоков с количеством (по preview-состояниям).
- Ячейки люков выделяются цветом, тултип перечисляет допустимые типы люков.
- Переводы en_us + ru_ru (включая фоллбеки для отсутствующих переводов машин).

## Технически

- Извлечение форм — прямое, через публичный API MI:
  `ReiMachineRecipes.multiblockShapes` (без рефлексии).
- Снимок строится заново на каждом EMI-reindex (в т.ч. после `/reload`),
  битые/пустые формы пропускаются с предупреждением в лог.
- Слой мутабелен только в пределах recipe-инстанса — тот же паттерн, что у
  собственной постраничной навигации EMI (`EmiIngredientRecipe.PageManager`).
