# ТЕРМОЯЯЯДЕРНЫЙ СИНТЕЗ

## Термоядерный реактор

<GameScene zoom="1" interactive={true} fullWidth={true}>

Термоядерный реактор — непревзойдённый источник энергии! Он может объединять дейтерий, тритий и/или гелий-3, превращая их в гелиевую плазму — самое мощное топливо в игре! Однако для запуска реакции требуется большое количество энергии.
