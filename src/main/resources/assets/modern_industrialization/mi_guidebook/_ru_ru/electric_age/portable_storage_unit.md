# Переносной накопитель

Переносной накопитель позволяет носить энергию в инвентаре. Его можно заряжать и разряжать щелчком правой кнопки мыши по любому накопителю.

<Recipe id="modern_industrialization:electric_age/battery/portable_storage_unit_asbl" />

По умолчанию он не может хранить энергию. Чтобы увеличить ёмкость, нужно заполнить его батареями: щёлкнуть правой кнопкой мыши по переносному накопителю с батареями в руке или по батарее с накопителем в руке. Чем выше уровень батарей, тем больше ёмкости они добавляют. Батарею можно забрать щелчком правой кнопки мыши по пустому слоту, но при этом вся энергия сверх оставшейся ёмкости будет потеряна.
