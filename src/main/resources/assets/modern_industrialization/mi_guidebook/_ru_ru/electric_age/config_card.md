# Расширенная настройка труб

Конфигурационная плата для предметной трубы позволяет маскировать трубы и копировать настройки предметных труб.

<Recipe id="modern_industrialization:tools/config_card" />

Если держать плату во второй руке, её настройки будут автоматически применяться к каждой устанавливаемой предметной трубе.
